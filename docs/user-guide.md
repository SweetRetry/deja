# Déjà 用户手册

Déjà 是你的本地视觉素材库。你不需要把图片导进一个封闭的软件里，只要打开硬盘上现有的任意文件夹，里面的图片和视频就会铺成一面素材墙。你可以在这里按画面内容找图、从网页随手收图、打星贴标签、归整目录，也可以一键清理重复副本。

---

## 1. 打开文件夹与设定范围

### 欢迎桌面

还没打开文件夹时，窗口里是一张散落着相片的桌面：

- 把鼠标停在相片上，或者按住相片拿起来，底部会浮现一段文字，展示 Déjà 是怎么记住画面内容的。
- 按住相片可以随手甩到桌面的任何角落。双击桌面空白处，散开的相片会重新聚拢回来。
- 点击左侧的「打开文件夹」按钮，或按 `⌘O`，在访达里选一个文件夹即可开始使用。

### 选择要索引的文件夹

第一次打开某个文件夹时，会弹出「选择要索引的文件夹」窗口：

- 列表里会列出所有子文件夹，以及每个文件夹里包含的图片和视频数量。
- 根目录下的文件始终会被索引。
- 如果有些子文件夹你不想在素材墙里看到（比如工程备份或未筛选的原片），取消勾选即可，然后点击「开始索引」。
- 取消勾选只是跳过索引，硬盘上的文件不会被改动或删除。
- 以后随时可以点击左侧栏顶部的文件夹名称，在菜单里选「选择索引范围…」重新勾选。

### 支持的文件格式

- **图片**。PNG、JPG、JPEG、GIF、WebP、HEIC、HEIF、TIF、TIFF、BMP、AVIF。
- **视频**。MP4、MOV、M4V、WebM、MKV。

## 2. 认识窗口三栏

打开文件夹后，窗口分为左、中、右三栏：

1. **左侧栏**。最上方是当前文件夹菜单，下面是「全部素材」「重复素材」和「文件夹」目录树。左下角显示索引进度和「设置」按钮。点击左上角的侧栏按钮可以收起或展开左侧栏。
2. **中央素材墙**。顶部是所在目录的面包屑导航、已开启的筛选条件、搜索框和「筛选」按钮。下方是素材墙。
3. **右侧检视面板**。选中一张素材时，这里显示大图预览、「查找相似素材」按钮、主色色条、文件属性、星级评分、标签和备注。选中多张素材时，这里会自动变成批量操作面板。按住面板左边缘左右拖动，可以调整面板宽度。

## 3. 浏览与整屏预览

### 在素材墙上浏览

- **点选与键盘移动**。单击任意缩略图即可选中。按方向键 `↑` `↓` `←` `→` 可以顺着画面位置上下左右移动焦点，按 `Home` 跳到第一张，按 `End` 跳到最后一张。
- **视频悬停预览**。把鼠标停在未选中的视频缩略图上，视频会直接在墙上静音循环播放。选中视频后，右侧检视面板会提供带进度条和音量控制的播放器。
- **面包屑跳转**。进入多层子文件夹后，顶栏左侧会显示路径层级，点击任意一层文件夹名字就能直接跳回去。

### 整屏预览

想看清原图细节时，用下面任意一种方式都能打开整屏预览：

- 双击墙上的缩略图。
- 选中素材后按 `Space`（空格键）或 `Enter`。
- 点击右侧检视面板上方的预览图。
- 在缩略图上右键，点击「预览」。

进入整屏预览后：

- **左右翻图**。按 `←` `→` 方向键切换上一张或下一张。
- **底部胶片条**。胶片条上方显示当前张数与总数（比如 `3 / 48`）。你可以直接点击胶片条上的小图跳转，也可以按住胶片条左右拖拽，或者在触控板上双指横向滑动来快速翻图。
- **退出预览**。再按一次 `Space`、按 `Esc`、点击右上角的 `×`，或者点击图片四周的空白处，都会退回素材墙。

## 4. 搜索、筛选与找相似

### 搜索素材

按 `⌘F` 或 `/` 可以直接把光标放进搜索框。输入文字后，素材墙会实时更新结果。在搜索框里按 `Esc` 会清空搜索词。

输入搜索词后，点开顶栏右侧的「筛选」按钮，可以切换两种**搜索方式**：

- **语义**。直接用日常语言描述画面里有什么（比如「雨夜的霓虹街道」「蓝天下的白裙」「木质桌面的咖啡杯」），同时也会合并文件名、标签和备注的匹配结果。每张图下方会显示名次和匹配百分比（比如 `#1 · 匹配 68%`）。
- **关键词**。只匹配文件名、标签和备注里的文字。

### 筛选与排序

点击顶栏右侧的「筛选」按钮，可以按条件缩小范围：

- **类型**。全部、图片、视频。
- **最低评分**。不限、3 星+、4 星+、5 星。
- **主色**。提供黑、灰、白、棕、红、橙、黄、绿、青、蓝、紫、粉 12 种颜色圆点。把鼠标停在圆点上能看到该颜色下有几张图，点击即可按主色过滤。
- **排序**。没有输入搜索词时，可以选择按「名称」「修改时间」「大小」或「评分」排列素材墙。

开启的筛选条件会变成小标签显示在搜索框左边，点小标签上的 `×` 可以单独关掉这一项，也可以在筛选面板底部点「重置筛选」一次全部清掉。

> **用一张图的主色直接筛选**。选中任意图片后，右侧检视面板的「主色」一栏会按比例画出这张图的主要颜色。把鼠标停在色条上能看色值和占比，直接点击某一段颜色，素材墙就会筛选出同色系的图。

### 查找相似素材

看到一张喜欢的图，想把库里构图、色调或内容相近的图都翻出来：

1. 选中这张图。
2. 点击右侧检视面板预览图下方的「查找相似素材」按钮，或者在缩略图上右键选择「查找相似素材」。
3. 素材墙会切换成「相似素材」视图，按相似程度从高到低排列。
4. 点击顶栏右侧的「返回全部素材」或按 `Esc`，即可回到原来的视图。

## 5. 从各处收集图片

打开文件夹后，新导入的图片默认放进**你当前正在看的子文件夹**；如果当前看的是「全部素材」，就放进根目录。遇到重名文件时，会自动在文件名后面加上 `2`、`3` 编号，不会覆盖已有的图。

Déjà 提供三种收集方式：

### 拖拽导入

- 从浏览器网页或者访达窗口，直接把图片拖进 Déjà 窗口的任意位置。
- 窗口浮现「松开以导入到『当前文件夹』」时松开鼠标即可。
- 从网页拖进来的图片会自动记下原始网页链接，保存在右侧面板的「备注」下方。

### 按 `⌘V` 粘贴导入

- 有些网页上的图片不让拖拽，你可以在网页上右键点「复制图片」，或者用截图工具把画面截到剪贴板里。
- 切回 Déjà 窗口（只要光标不在文字输入框里），直接按 `⌘V`，剪贴板里的图片就会存进当前文件夹。

### 切回窗口时的剪贴板提示卡

- 当你在浏览器或其他软件里复制了一张图片，再切回 Déjà 窗口时，左侧栏下方会自动浮现一张「剪贴板里有一张图片」卡片，显示那张图的缩略图和宽高像素。
- 点击卡片上的「导入到『当前文件夹』」按钮即可收进库里。
- 如果不想导入，点卡片右上角的 `×` 忽略即可。同一张复制的图片只会提醒一次。

### 导入后的定位与撤回

每次导入完成后，窗口底部会弹出一条提示，带有两个按钮：

- **定位**。直接滚动到刚导入的那张图并选中它。
- **撤回**。把刚才导入的文件立刻删掉，恢复原状。

## 6. 打星、贴标签与写备注

在右侧检视面板里所做的全部标记都会**自动保存**，不需要点保存按钮：

- **星级评分**。
  - 选中素材后，直接按键盘上的数字键 `1` 到 `5` 就能打星，按 `0` 清除星级。
  - 也可以在右侧检视面板的「评分」一栏点击星星；再点一次当前的星数就能清零。
  - 打过星的素材，缩略图右下角会一直带着星标。
- **标签**。
  - 在「标签」输入框里打字，按 `Enter` 即可贴上标签。
  - 输入时会弹出你在这个库里用过的常用标签，方便直接点选。
  - 点击已有标签上的 `×` 或按退格键即可删掉标签。
- **备注与来源**。
  - 在「备注」框里直接写字即可。停笔不到一秒（或点到别处），右上角就会亮起绿点并显示「已保存」。
  - 从浏览器导入的图，备注框下方会自动显示「来源」网址。

## 7. 整理文件夹与批量操作

### 新建文件夹与空文件夹

- **新建文件夹**。点击左侧栏「文件夹」标题右边的 `+` 按钮，输入文件夹名字后按 `Enter`，就会在根目录下建好新文件夹，并直接切进去。新建时按 `Esc` 可以取消。
- **新建子文件夹**。在左侧栏的任意文件夹上点击右键，选「新建子文件夹」，就能在它下面再建一层目录。
- **显示或隐藏空文件夹**。点击左侧栏「文件夹」标题右边的 `…` 按钮，可以勾选或取消「显示空文件夹」（在「设置」里也能改）。你当前点开的文件夹就算还没有图，也一定会留在侧栏里。

### 多选素材

想要一次整理多张图时：

- **加选与减选**。按住 `⌘` 键逐个点击缩略图，可以把多张图一起勾选上（或者取消勾选）。选中的缩略图左上角会显示对勾。
- **全选**。按 `⌘A` 选中当前墙上的全部素材。
- **取消多选**。按 `Esc`，或者点击右侧面板里的「取消选择」按钮，就会退回单张选中状态。

当勾选了多张素材时，右侧检视面板会变成「已选 N 项」批量面板，显示这批文件的总大小和缩略图预览。

### 移动素材到其他文件夹

单张图或多选的一批图，都可以用下面三种方式移动：

1. **直接拖到左侧栏文件夹上**。按住墙上的缩略图，拖到左侧栏的目标文件夹上松开。如果目标子文件夹藏在折叠的父文件夹里，拖过去停半秒钟，父文件夹就会自动展开。
2. **右键菜单移动**。在缩略图上点击右键，选「移动到」（多选时是「将 N 项移动到」），再点目标文件夹。
3. **右侧面板移动**。多选素材后，点击右侧面板的「移动到…」按钮选择目标文件夹。

> **标记跟着文件走**。在 Déjà 里把素材移到别的子文件夹时，你之前打的星级、贴的标签和写的备注都会自动跟着移过去，不会丢失。

### 移到废纸篓与在访达中查看

- **移到废纸篓**。在缩略图上右键点「移到废纸篓」，或者在多选面板里点击红色的「移到废纸篓」按钮，文件就会被移进系统的废纸篓。如果不小心删错了，去系统废纸篓里选「放回原处」就能恢复。
- **在访达中显示**。点击右侧检视面板右上角的文件夹小图标，或者在缩略图上右键点「在访达中显示」，系统就会打开访达窗口并高亮定位到那个文件。

## 8. 找出并清理重复素材

素材攒多了，不同目录里常会存下同一张图，或者同一张图既有原图又有缩小压过的版本。Déjà 会在后台自动比对全库图片，帮你把这两类重复找出来：

- **相同副本**。两个文件一模一样。
- **相近副本**。同一张图被改过尺寸、重新压缩或换过格式另存的版本。

### 清理步骤

1. 点击左侧栏上方的 **「重复素材」**（右边的数字代表一共有多少张图涉及重复）。
2. 素材墙会把每一组重复的图单独排成一行。每一组的第一张都是 Déjà 建议你留下的版本（优先挑分辨率最高、打星最高、文件最大、保存时间最早的那张），缩略图下方会写着：
   - 第一张显示 `保留 · 宽×高`
   - 后面的显示 `相同副本 · 宽×高` 或 `相近副本 · 宽×高`
3. 顶栏会提示共有几组重复、多出几个副本，点击旁边的 **「选中多余副本」** 按钮。
4. 这时每组的第一张「保留」图都会被安全跳过，其余多余副本会被一次性全部勾选。
5. 点击右侧面板的 **「移到废纸篓」**，所有多余副本就一次清理干净了。
6. 点击顶栏右侧的「返回全部素材」或按 `Esc` 回到日常浏览。

## 9. 索引进度与菜单栏图标

### 左下角索引状态

打开新文件夹或放入新图后，左下角会显示后台处理的进度：

1. **生成预览**。正在生成缩略图、读取尺寸并提取主色。
2. **建立语义索引**。正在分析画面内容，用来支持按画面描述搜图。
3. **索引已完成**。亮起绿点，代表所有素材都已处理完毕。

如果电脑正在做其他重负载工作，你可以随时点击进度文字右边的暂停按钮，让索引先停下来，之后再点播放按钮继续。

### 关掉窗口与菜单栏常驻

- 点击窗口左上角的红色关闭按钮时，Déjà 只是收起窗口，**不会退出**，而是留在屏幕顶部的系统菜单栏里继续替你看着文件夹。
- 点击屏幕顶部菜单栏里的 Déjà 图标，可以：
  - 点击 **「显示 Déjà」** 重新唤出主窗口。
  - 在 **「最近的文件夹」** 里直接切换到以前打开过的其他素材库。
  - 点击 **「退出 Déjà」** 彻底关闭软件。

## 10. 设置项一览

按 `⌘,` 或点击左下角的齿轮图标打开「设置」，每一项改动都会立刻生效：

### 外观

| 设置项 | 选项 | 作用 |
| --- | --- | --- |
| 主题 | 跟随系统 / 浅色 / 深色 | 切换窗口配色，默认是深色 |
| 布局 | 瀑布流 / 方格 | 「瀑布流」保持每张图原本的长宽比，「方格」统一裁成整齐的正方形 |
| 缩略图 | 小 / 中 / 大 | 调整素材墙上缩略图的尺寸与列数 |
| 文件名 | 显示 / 隐藏 | 是否在每张缩略图下面显示文件名 |
| 空文件夹 | 显示 / 隐藏 | 没有图片和视频的空子文件夹要不要在左侧栏列出来 |

### 语义搜索

| 设置项 | 选项 | 作用 |
| --- | --- | --- |
| 按画面内容搜索 | 开启 / 关闭 | 开启后可以用自然语言描述画面找图（约占 0.8 到 1.2 GB 内存）；关闭后只按文件名、标签和备注搜索 |
| 最低匹配度 | 不限（0%）至 100% | 拖动滑块设定门槛，过滤掉语义搜索里不太像的结果 |
| 低于匹配度的结果 | 置暗 / 隐藏 | 「置暗」让低于门槛的图变淡留在墙上，「隐藏」直接把它们从结果和预览里藏起来 |
| 空闲后释放模型 | 5 分钟 / 15 分钟 / 30 分钟 / 不释放 | 一段时间不搜图就自动释放内存，下次搜图时多等约 3 秒重新加载 |

| 按键 | 场景 | 作用 |
| --- | --- | --- |
| `⌘O` | 欢迎桌面 | 打开文件夹 |
| `⌘F` 或 `/` | 浏览素材时 | 聚焦到顶栏搜索框 |
| `⌘,` | 任何时候 | 打开设置窗口 |
| `⌘V` | 浏览素材时（未在输入框打字） | 把剪贴板里的图片存进当前文件夹 |
| `⌘ + 点按` | 素材墙 | 加选或取消勾选某张素材 |
| `⌘A` | 素材墙 | 全选当前墙上的所有素材 |
| `↑` `↓` `←` `→` | 素材墙 / 整屏预览 | 在墙上移动选中焦点；在整屏预览里左右翻图 |
| `Home` / `End` | 素材墙 | 跳到第一张 / 最后一张素材 |

| `Space` | 整屏预览 | 关闭整屏预览 |
| `1` 至 `5` | 选中素材时（未在输入框打字） | 给当前素材评 1 到 5 星 |

| `Esc` | 预览 / 多选 / 搜索 / 相似与重复视图 | 关闭整屏预览、取消多选、清空搜索框，或退回全部素材 |

## 12. 备份与迁移说明

- **原文件原地不动**。你的图片、视频和子文件夹结构完全保持原样，在访达里怎么看就是怎么放的。
- **标记跟着文件夹走**。你打的星级、贴的标签、写的备注以及排除的子文件夹设置，都保存在这个文件夹下面的隐藏目录 `.deja` 里。
- **换电脑或备份**。只要把整个素材库文件夹拷进移动硬盘、网盘或另一台 Mac，用 Déjà 打开同一个文件夹，所有的标签、评分和备注都在，不需要导出或导入任何数据库。
